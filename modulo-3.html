Descripción del módulo

En este módulo se abordan los requisitos técnicos para implementar accesibilidad mediante código. Se trabajan las buenas prácticas en HTML semántico, CSS y JavaScript, así como la estructura del árbol de accesibilidad, la gestión del foco, la navegación por teclado y la adaptabilidad a dispositivos.

También se introduce WAI-ARIA para la creación de elementos interactivos complejos y se utilizan herramientas de inteligencia artificial para generar o validar código accesible.

Importancia profesional: forma desarrolladores web con capacidad para garantizar la accesibilidad técnica de los productos digitales según estándares internacionales.

Objetivos

HTML semántico

Crearás documentos bien estructurados y comprensibles para tecnologías de asistencia.

Contenido accesible

Diseñarás y validarás tablas, formularios, imágenes funcionales y gráficos.

CSS e interacción

Aplicarás accesibilidad en tipografía, color, foco, responsive, movimiento y animaciones.

WAI-ARIA e IA

Desarrollarás componentes interactivos complejos y usarás IA para apoyar la generación y validación de código accesible.

Clase 3. CSS y accesibilidad

Clase 4. WAI-ARIA básico

Clase 5. WAI-ARIA avanzado

  • 5.1 Desarrollo de elementos interactivos.
  • 5.2 Uso de herramientas IA para generar código accesible.

Metodología

El curso combina trabajo autónomo en el campus virtual de la UdL, sesiones síncronas y actividades prácticas para aplicar progresivamente los contenidos del módulo.

Preparación previa

Antes de las sesiones, accederás a la plataforma para revisar vídeos, materiales y actividades introductorias del tema.

Trabajo autónomo guiado

Realizarás actividades prácticas de autoaprendizaje, participarás en foros y consultarás materiales complementarios opcionales.

Sesiones síncronas

Participarás en clases en directo con el profesorado para resolver dudas, trabajar ejemplos y profundizar en los contenidos clave.

Aplicación práctica

Desarrollarás actividades prácticas para consolidar lo aprendido y trasladarlo a casos reales.

Trabajo final del módulo

Completarás una actividad final evaluable que permitirá demostrar la adquisición de los resultados de aprendizaje.

Evaluación del módulo

Para la evaluación del módulo el alumnado implementará una landing page utilizando HTML, CSS y JavaScript.

La implementación se realizará conforme a los requisitos establecidos en el enunciado de la tarea. No se superará el módulo si el resultado del trabajo es “insuficiente”.
